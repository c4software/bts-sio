## Générateurs de sites statiques

Les outils suivants permettent de générer des sites « clients » dynamiques ou statiques en utilisant uniquement du HTML, CSS et JS. Ils sont donc hébergés sur des plateformes de type Netlify, Github Pages, etc. Parfait pour un portfolio ou une documentation.

- [VitePress](https://vitepress.dev/) <- Générateur de site statique basé sur VueJS.
- [Astro](https://astro.build/) <- Générateur de site statique.
- [Docusaurus](https://docusaurus.io/) <- Générateur de documentation.
- [NextJS](https://nextjs.org/) <- Framework fullstack basé sur React.

## Hébergement

Deux catégories :

- Les sites statiques (HTML, CSS, JS)
- Les sites dynamiques (PHP, NodeJS, Python, Ruby, Java, etc.)

::: tip Point vocabulaire
CI/CD signifie « Continuous Integration / Continuous Delivery ». Il s'agit d'un ensemble de techniques permettant de déployer automatiquement un site web à chaque modification du code source. Les plateformes proposant ce service sont souvent gratuites pour les sites statiques et intègrent une interface permettant de gérer les déploiements (exemple Netlify).
:::

## Sites statiques

- [Netlify](https://www.netlify.com) <- CI/CD, Simple, « gratuit », avec une interface web de gestion.
- [Cloudflare Pages](https://pages.cloudflare.com/) <- CI/CD, « gratuit », très généreux sur le free-tier.
- [Vercel](https://vercel.com/) <- CI/CD, « gratuit », la référence pour les projets NextJS.
- [Surge.sh](https://surge.sh/) <- CI/CD, Simple, « gratuit », un poil plus technique.
- [Gitlab Pages](/tp/ci/pages.md) <- CI/CD
- [Github Pages](https://pages.github.com/) <- CI/CD (Gratuit, mais sans interface de gestion)
- [Firebase Hosting](https://firebase.google.com/docs/hosting) <- CI/CD (Gratuit, mais sans interface de gestion)

## Sites dynamiques

- [Heroku](https://www.heroku.com/) <- CI/CD, Plus complet, mais un peu plus « complexe ». Payant (plus d'offre gratuite depuis fin 2022).
- [OVH](https://www.ovh.com/) <- Hébergeur classique à base de serveurs dédiés ou mutualisés.
- [Web Hosting OVH](https://www.ovhcloud.com/fr/web-hosting/) <- Hébergement mutualisé à petit prix.
- [AlwaysData](https://www.alwaysdata.com/fr/) <- Free-tier de 100 Mo pour vos projets.
- [Page Perso Free](https://assistance.free.fr/?search=Pages%20Perso&offer=tags-92) <- 10Go gratuits si abonné Free.
- [Railway](https://railway.app/) <- Payant mais avec une offre de test de 500h.
- [Render](https://render.com/) <- CI/CD, free-tier pour les petits projets (avec mise en veille).
- [Fly.io](https://fly.io/) <- Déploiement de conteneurs Docker proche de vos utilisateurs.
- [Clever Cloud](https://www.clever-cloud.com/) <- PaaS français, données hébergées en France.
- [Coolify](https://coolify.io/) <- PaaS open source à auto-héberger sur votre propre serveur (type Netlify/Heroku chez vous).
