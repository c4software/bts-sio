# Option Parcours de certification complémentaire

Le BTS SIO propose une option facultative, le **Parcours de certification complémentaire**. L'idée est simple : construire, par vous-même, une démarche d'acquisition de compétences qui viennent compléter le diplôme. Cette page vous explique comment fonctionne l'option, puis vous donne un point de départ avec une liste de plateformes classées par spécialité.

::: details Table des matières
[[toc]]
:::

## Comment fonctionne l'option ?

### Le principe

La préparation d'une certification professionnelle vise la reconnaissance d'une expertise spécifique, dont vous pourrez vous prévaloir sur le marché du travail en plus de votre diplôme. Une certification complémentaire répond à deux besoins :

- **se spécialiser** dans un domaine des technologies informatiques et numériques (réseau, cloud, cybersécurité, développement mobile, etc.) ;
- ou **renforcer des compétences transversales** (gestion de projet, anglais, bureautique, etc.).

Il ne s'agit donc pas d'un cours de plus, mais d'un **projet personnel** que vous construisez et que vous menez sur les deux années du BTS.

### Ce qui est évalué

L'épreuve évalue **la démarche** que vous avez entreprise pour acquérir des compétences complémentaires, en vue de votre insertion ou de votre évolution professionnelle. Autrement dit : on regarde autant le chemin que le résultat. Une certification obtenue est un plus, mais un parcours cohérent, documenté et argumenté compte tout autant.

::: tip Ce que cela implique pour vous
Gardez une trace de tout ce que vous faites : comptes créés, modules suivis, badges obtenus, difficultés rencontrées, choix effectués (et abandonnés). Ce journal sera la matière première de votre présentation.
:::

### Objectifs de la première année

En première année, l'objectif n'est pas d'obtenir une certification, mais de poser les bases :

1. **Mettre en place un parcours cohérent** : choisir un domaine en lien avec votre spécialité (SISR ou SLAM) et votre projet professionnel.
2. **Construire un projet** : quelles compétences visez-vous ? Quelles certifications existent dans ce domaine ? Lesquelles sont accessibles à votre niveau ?
3. **Définir des objectifs réalistes** : mieux vaut un parcours modeste et mené à terme qu'un plan ambitieux abandonné en cours de route.
4. **Débuter les premières certifications** : commencer par des modules et badges gratuits, qui serviront de marches vers une certification plus reconnue.

### Quelques pistes de certifications

Pour vous donner une idée de ce qui existe (la liste est loin d'être exhaustive) :

- **Systèmes et réseaux** : [LPIC-1](https://www.lpi.org/fr/our-certifications/lpic-1-overview/) (Linux), [Red Hat RHCSA](https://www.redhat.com/fr/services/certification/rhcsa), les certifications [Cisco](https://www.netacad.com/) (CCST, CCNA).
- **Cloud** : [Microsoft Azure Fundamentals (AZ-900)](https://learn.microsoft.com/fr-fr/credentials/certifications/azure-fundamentals/), [AWS Cloud Practitioner](https://aws.amazon.com/fr/certification/certified-cloud-practitioner/), [Google Cloud Digital Leader](https://cloud.google.com/learn/certification/cloud-digital-leader).
- **Cybersécurité** : les parcours [TryHackMe](https://tryhackme.com/) et [Root-Me](https://www.root-me.org/), [SecNumacadémie](https://secnumacademie.gouv.fr/) de l'ANSSI, puis des certifications d'entrée comme CompTIA Security+.
- **Développement** : les certificats [freeCodeCamp](https://www.freecodecamp.org/), [Microsoft Learn](https://learn.microsoft.com/fr-fr/training/), [OpenClassrooms](https://openclassrooms.com/), les certifications Android ou Kotlin.
- **Formations payantes** : [Udemy](https://www.udemy.com/) et [Alphorm](https://www.alphorm.com/) proposent des cours de préparation aux certifications (attendez les promotions, elles sont fréquentes).

Pour choisir, une recherche « certifications IT les plus recherchées » vous donnera une idée des demandes actuelles du marché. Croisez ces informations avec vos envies et votre spécialité, et parlez-en avec votre professeur.

## Les plateformes : un point de départ

Ce qui suit est une liste de plateformes pour apprendre et vous entraîner. Ce n'est pas la liste des certifications, mais l'endroit où **commencer** votre parcours : c'est là que vous ferez vos premiers modules, obtiendrez vos premiers badges, et découvrirez ce qui vous plaît.

### Comment lire les tableaux

- **Statut** : **G** = gratuit, **F** = freemium (démarrage gratuit, contenu premium payant). Dans tous les cas, la partie gratuite suffit pour ce que je vous demande.
- **Niveau conseillé** : **1re** (dès la première année), **2e** (plutôt en deuxième année, quand les bases sont acquises), **1re / 2e** (utile tout au long du BTS).
- Pas de panique, il ne s'agit pas de tout faire. Choisissez **une ou deux plateformes** en lien avec votre projet, créez un compte, et avancez un peu chaque semaine. La régularité compte plus que la quantité.

::: tip Un bon réflexe
Les certificats et badges gratuits (freeCodeCamp, Microsoft Learn, Cisco NetAcad, TryHackMe…) ont leur place sur votre CV et dans votre portfolio. Ils constituent aussi les premières étapes de votre parcours de certification : pensez à les mentionner lors de votre recherche de stage.
:::

### Par où commencer ?

Si vous ne savez pas quoi choisir, voici une proposition simple :

- **En 1re année, SLAM** : freeCodeCamp ou The Odin Project pour le web, SQLBolt pour le SQL, Learn Git Branching pour Git, et CodinGame pour s'amuser avec l'algorithmique.
- **En 1re année, SISR** : OverTheWire (Bandit) pour Linux, Cisco Networking Academy pour le réseau, Root-Me ou TryHackMe pour la découverte de la cybersécurité.
- **En 2e année** : ajoutez une plateforme cloud (Microsoft Learn ou AWS Skill Builder), et pour les curieux de la sécurité, PortSwigger ou Hack The Box.

C'est à vous de jouer ! Et n'oubliez pas de noter ce que vous apprenez : c'est la base de votre parcours, et c'est aussi ça, la veille. Pour les sites d'actualité, les newsletters et les chaînes à suivre, rendez-vous sur la page [Ressources veille & développement](/tp/veille/ressources.md).

👋 Si vous avez des questions, ou si vous connaissez une plateforme qui mériterait d'être dans cette liste, n'hésitez pas.
