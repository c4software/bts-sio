# Les TP mobile

Vous trouverez ici la liste des TP mobile, dans l'ordre dans lequel je vous conseille de les réaliser. Le parcours s'appuie sur Android et Jetpack Compose, la façon moderne d'écrire des applications Android.

::: warning Les prérequis
La programmation orientée objet doit être acquise avant de commencer (voir [les concepts](/pages/categories/les-concepts.md)).
:::

## Étape 1 : Les bases d'Android Compose

Les TP suivent [le cours Android Base](/cours/android_base.md) et [le cours Android Compose](/cours/android_compose.md).

1. [Découverte des bases d'Android](/tp/android/compose/android-base.md)
2. [Créer une interface dynamique (les composants)](/tp/composants/android.md)

## Étape 2 : Communiquer avec l'extérieur

L'application mobile prend tout son sens quand elle échange avec le monde : le réseau et le Bluetooth.

1. [Android Compose, une liste et une API REST](/tp/android/compose/dirty-api.md)
2. [Android et BLE](/tp/android/compose/android-ble.md)

::: tip Les supports associés
[Cours Android + HTTP](/cours/android_http.md) et [cours Android + BLE](/cours/android_ble.md).
:::

## Étape 3 : Les projets

Pour mettre en pratique l'ensemble des notions sur un projet complet :

1. [Télécommande Bluetooth & Réseau](/tp/android/view/app-ble-network.md)
2. [Application Client / Serveur](/tp/android/view/app-avance-android.md)

::: tip Et ensuite ?
[L'introduction à Kotlin Multiplateforme](/tp/android/compose-multiplateforme/introduction.md) pour cibler plusieurs plateformes avec le même code, et la catégorie [Le mobile](/pages/categories/le-mobile.md) pour l'ensemble des ressources.
:::
